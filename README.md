# D4AI-1

Standalone **D4AI** Android app (Code Assist / Android Studio).

- **Offline-first**: chat UI lives in `app/src/main/assets/index.html`
- **Splash**: navy + D4AI branding
- **Online**: answers via Pollinations text API when the network is available

## Code Assist

1. Clone `https://github.com/amurunoghenetejiri/D4AI-1`
2. Open the **repo root** (must see `settings.gradle` + `app/`)
3. Sync / Run

Package: `com.d4tech.d4ai`
